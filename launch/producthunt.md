Name (<=40 chars):
Keyrate

Tagline (<=60 chars):
A typing test that shows which keys slow you down.

Description (<=260 chars):
A typing test that lights the five keys you miss most and charts your speed second by second. Common words from twenty public domain novels. Six modes, light and dark, no account. Web, iPhone, iPad and Mac.

Topics (3):
Productivity, Education, Web App

First comment (maker story):
Most typing sites bury the test under themes, accounts and a leaderboard. The only thing anyone really opens the page for is their speed, so I built a page that gives you that and nothing in the way.

Keyrate is one test. Words appear, you type them, and the page tells you how fast. Then it shows you why. A keyboard lights up the five keys you miss most, and a line shows your speed second by second. Accuracy looks at the text you end with, so a typo you fix does not cost you accuracy.

The words are common English, counted from twenty public domain novels. I did not copy a list from another typing site.

The same test runs on the web, on Apple devices and in a terminal app. Each version checks itself against one shared file of expected scores, so a result means the same thing everywhere.

Your best score stays on your device. No account, no leaderboard, no server keeping a history. It is free.
